# Finishing checks without repeatedly rereading the Bible

Operational supplement, 16 October 2026. Implements FINISHING_OUTPUT_CONTRACT.md and the owner's request to prevent forgotten textures/effects. The adopted Bible and owner approval gates remain authoritative.

For each new renderer, load the governing version/hash snapshot and only changed relevant modules. Create one short shot-specific coverage manifest before animation. It maps each applicable requirement to its code, active time/window, expected visible result and actual rendered proof. Review it before capture, then against the actual encoded result. Re-reading all unchanged source manuals after each encode costs context without demonstrating execution.

Required coverage: material texture; moving grain; camera/transition blur with sharp holds; selective focus and matching surround shading; brief focus hunt; restrained chromatic separation; mechanical jitter; exposure variation; local ink bleed and edge boil; protected captions; exact protected ending when included; source/sequence continuity; complete narration tail; audible action SFX and musical development.

`finishing_audit.py` checks declared applicability, evidence-file hashes, source hashes, proof metrics and review status. It does not certify artistic likeness or audibility. An effect-on/off pixel change establishes execution, not beauty. Match masks/anchors, inspect actual phone-size encoded frames, watch transitions, and listen to final audio separately. Do not add inappropriate effects merely to fill a checklist. A deliberate exclusion requires a specific explanation; a short passage without the full-film ending may exclude endcard testing, never claim that ending passed.

Before delivery:

1. Validate source/config/dependency hashes and the applicable sequence review; this detects drift from approved source.
2. Render representative first, difficult intermediate, settled, transition and final states, with effects independently on/off. Same time/inputs must be deterministic. Hold underlying picture and exposure constant to isolate temporal grain. Test selective focus/shading in selected and peripheral regions. Test blur envelopes settling back to zero.
3. Compare protected caption pixels after finishing; test the exact endcard unchanged when it exists in the actual sequence. Label missing full-film context honestly.
4. Decode and inspect actual MP4/WebM frames, including a phone-scale grain/texture check. Verify full audio tail, cue events, music and subjective listening status independently. Technical presence does not imply owner creative approval.
5. Save coverage, proof files, source and actual exports in GitHub with byte receipts. A warning or REVISE finding blocks FINAL; previews can be delivered explicitly for review with findings visible.

The cold-metal motion-v1 passage is the first execution example. This adds a reusable audit and evidence path; it does not silently replace existing native release validation or authorize bypassing the pre-render freeze gate. Both the existing native contract and this coverage audit apply where declared. User-facing videos contain the story, not debug checklists or internal workflow labels.

Proof freshness safeguard: starting a new cold-metal proof run removes the previous runtime report. A successful report binds the exact picture renderer, source scene, finishing adapter and proof script hashes. Preflight checks those bindings independently of the coverage manifest. A failed proof run or source drift cannot inherit an older green result. The hidden-panel pixel test also verifies that an unrevealed source plane draws nothing.
