## Classifications
G = created full-screen graphic; O = created overlay over recorded footage; C = created composite **overlay part only**; R = raw live action/interview/archive moving film **skip**; P = historical photo/filmed source still/map pixels **skip**; X = unresolved/uncertain.

## Red lines
- Real people/recorded action, golf swings, historical image content, raw photographs and film, military action, natural water, drone shots, footage cuts, camera shake and documentary interviews are **not** transferable graphics.
- If an authored arrow or caption tracks a recorded subject, study only the relative attachment and occlusion concept. In original demos substitute the subject with independently authored moving coordinate geometry.
- Original Vox artwork, graphics frames, footage, source music, voice or fonts are NEVER included in the public GitHub project, the distributed learning archive or a channel episode.
- Copyright-relevant local source analysis frames were not published. Public evidence is source URL + clip time/frame indexes + descriptions and original test screenshots.
- The historical-map sections of V04 contain primary/substitute editorial framing, which is outside *graphics technique* endorsement; any future film researches its geographic and political facts anew.
